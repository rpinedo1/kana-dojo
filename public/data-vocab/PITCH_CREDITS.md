# Pitch accent data

`pitch.json` is generated by `scripts/generate-vocab-pitch.ts` from the pitch
accent list in [Kanjium](https://github.com/mifunetoshiro/kanjium)
(commit `9ebca45`), licensed under
[Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
`pitch.json` is a derived work and is shared under the same license.

Each value is a list of downstep numbers (the mora after which the pitch
drops; 0 means it never drops), most common first, keyed by `word|kana`.
